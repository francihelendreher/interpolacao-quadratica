y = ax² + bx + c < #busquei do fundo do baú

Depois, utilizei os três pontos para encontrar os valores de a, b e c, chegando à função:

y = -3x² + 11x - 5

Com a função encontrada, calculei a concentração no tempo de 2,5 segundos e obtive:
